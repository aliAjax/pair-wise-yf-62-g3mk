# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 调度账规则

- **派单校验**：搜索区须为执行中（规划/关闭不接单）；单位须在线、在可用时段内、剩余续航大于 0；同一单位不能同时挂在两个进行中任务上。
- **乐观锁**：单位带占用版本号，派单提交读取时的版本；两名值班员同时提交同一单位占用时先写入生效，后到者收到版本变化提示并重新选择。
- **离线合并**：离线期间上报的位置按编号（单位）与观测时刻暂存回网队列；恢复在线（或手动合并）时入账，同一观测时刻保留接收时刻较新的一条，另一条置为待核对，由值班员采用或留档。
- **失效退回**：搜索区关闭或单位续航耗尽时，相关进行中任务失效退回、释放单位并重算覆盖率；已完成任务继续留档。
- **覆盖率** = 搜索区前期基础 + 在档任务贡献（任务退回不计），封顶 100。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist 保存。
