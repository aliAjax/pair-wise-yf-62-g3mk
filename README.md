# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

调度账：搜索区、执行单位、任务单接成一份账，一切变更按序入账（`src/lib/ledger/`），页面底部可查流水。

- 派单先校验：搜索区须为执行中；单位须可派、可用时段覆盖任务窗口、剩余续航不低于任务消耗；任一不满足即整单拒接并留痕，一艘船不会同时挂在两个进行中任务上。
- 离线记录回网后按编号与观测时刻合并入账：重复编号忽略；同一观测时刻保留较新接收的位置，另一条进待核对队列，可人工采纳或作废。
- 区域关闭或单位续航耗尽：相关活跃任务失效退回、单位释放、覆盖率按未失效任务的扫测贡献重算；已完成任务留档不受影响。
- 乐观并发：开具派单时快照单位版本，两名值班员同时提交同一单位，先写入者生效，后到者看到版本已变化并重新选择（可用单位卡片上的"他员抢占"模拟）。
- 离线模拟与低带宽模式可切换；离线时位置包先缓存，回网自动合并；本地数据由 Zustand persist 保存。
